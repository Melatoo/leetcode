# 🚀 LeetCode Solutions

Welcome to my **LeetCode** solutions repository!

This space is dedicated to documenting my journey of studying algorithms, data structures, and problem-solving. All solutions here are developed with a focus on achieving the best possible time and space complexity.

## 💻 Tech Stack

- **JavaScript (Node.js)**: The primary language used for all solutions.

## 📂 Repository Structure

The repository is organized into folders. Each folder corresponds to a specific problem number on LeetCode.

Example structure:
```text
📦 leetcode
 ┣ 📂 0138 (Copy List with Random Pointer)
 ┣ 📂 0140 (Word Break II)
 ┣ 📂 0767 (Reorganize String)
 ┣ 📂 2357 (Make Array Zero by Subtracting Equal Amounts)
```

Inside each folder you will find:
- The main solution file (e.g., `mySolution.js`).
- Local test cases (if applicable).

## 🏃 Running Tests

The problems are validated locally using a custom testing CLI configured in the project. 
To run tests for a specific problem, navigate to the problem's folder and execute the test command:

```bash
cd 0140
leetcode-test
```
